---
title: Public types
subtitle: Stable TypeScript contracts in Jeston 1.x
---

The documented types in `@hedronjs/jeston` are the compatibility boundary for application and adapter authors.

| Type | Purpose |
| --- | --- |
| `PageModule` | React page, data loading, headers, and revalidation |
| `ApiHandler` | Typed API method handler |
| `RequestContext` | Request, response, URL, params, body, state, environment, request ID, deadline, and abort signal |
| `ResponseLike` | JSON, body, redirect, stream, or React response with optional headers and tags |
| `AppConfig` | Runtime, cache, security, logging, observability, health, and limits |
| `CacheAdapter` | Async cache get/set/delete with optional fresh reads, tags, clear, and bounded close |
| `JobQueue` | Durable enqueue contract with optional delay, idempotency, tags, retry metadata, and bounded close |
| `StorageAdapter` | Streaming object storage with optional abort signals and tags |
| `MetricsAdapter` | Counter and histogram methods with optional gauges and flush/close |
| `HealthRegistry` | Named checks with deadlines, abort signals, status, latency, and timestamped reports |

Import types from the package entrypoint. Do not rely on generated internal files that are not documented as public. Optional additions do not require existing adapters to implement new methods.
