---
title: Deployment
subtitle: Deploy Jeston as a portable Node.js application
---

Jeston production output is a regular Node.js application. Build in CI, ship the application and `.meu` output, install production dependencies, and run `jeston start` or the generated server entrypoint.

```bash
npm ci
npm run typecheck
npm run build
npm run start -- --port 3000
```

## Container example

```dockerfile
FROM node:22-bookworm-slim AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:22-bookworm-slim
WORKDIR /app
ENV NODE_ENV=production
COPY --from=build /app ./
EXPOSE 3000
CMD ["npm", "run", "start", "--", "--port", "3000"]
```

The application needs access to its secrets, database, cache, and storage adapters at runtime. Use a reverse proxy or managed ingress for TLS, compression, request filtering, and rate limiting at the edge.
