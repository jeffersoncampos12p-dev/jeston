---
title: Ecosystem and operational support
subtitle: How Jeston grows beyond the core package
---

Jeston's ecosystem is organized around public contracts, independently versioned adapters, reproducible contract tests, and operational documentation. The core package remains small; provider SDKs, templates, devtools, and deployment integrations live in separate packages.

The support model is designed to grow in layers. Maintainers provide core compatibility guarantees and security releases. Official integration teams maintain provider adapters. Community maintainers publish adapters under documented compatibility rules. Cloud and infrastructure providers can offer managed operational support without requiring the framework to depend on one hosting platform.

The project should measure ecosystem health through maintained packages, release cadence, issue response, compatibility matrices, examples, migration guides, and production references. A large catalog is useful only when integrations are tested, documented, secure, and actively maintained.
