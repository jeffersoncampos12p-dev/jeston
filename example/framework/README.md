# Ryvax framework copy

This directory contains the local Ryvax package used by the Pulseboard example. It mirrors the public package so the example can be built from a clean checkout without relying on a parent directory or an unpublished version.

For the complete framework documentation, see the repository root `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `API-COMPATIBILITY.md`, and the Mintlify source under `path/to/docs/`.

The package exposes the `ryvax` CLI and the runtime APIs from `src/`. Keep this copy synchronized with the release version used by the example.
